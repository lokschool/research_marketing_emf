Pipeline Overview

This report is generated by an automated multi-phase intelligence pipeline that crawls company websites, analyses unstructured content with multiple AI models, validates evidence, and scores sell opportunities. Each data point is traceable to a specific crawled page or external source.

Phase Details

Phase A — Solution Ingestion: Solution documents (PDFs, marketing materials) are ingested and analysed to extract core value propositions, features, target industries, and pricing models. This builds the reference model for pain-solution matching in Phase C. Input: solution PDFs and docs. Output: structured solution profile.
Phase B — Company Collection: Target company websites are crawled using a 15-worker concurrent crawler. Pages are selected by an LLM that reads sitemaps and navigation to identify high-value pages (About, Products, Pricing, Blog). HTML is extracted into structured text via BeautifulSoup. External signals (LinkedIn hiring, news, industry reports) supplement the crawl data. Input: company domain + sitemap. Output: extracted page content + structured company data.
Phase C — Multi-Model Analysis: Three independent AI models (DeepSeek V3, MiniMax M3, MiMo-v2.5) analyse each company's extracted content to identify pain points. Each pain point includes: label, description, urgency, evidence linking, and confidence score. Results are cross-validated: points from different models are merged via Jaccard similarity if they describe the same underlying problem. An evidence validation agent verifies each claim against the crawled pages, assigning source URLs. Input: structured company data + solution profile. Output: validated pain points with evidence URLs.
Phase D — Report Generation: All validated data flows into the report builder. Sell scores are computed from 5 weighted dimensions. Charts are rendered with Chart.js. Narrative summaries are generated for each company. The Deep Market Analysis section uses DeepSeek V3 to synthesise cross-market insights from the complete dataset. All reports are published as static HTML with evidence links, internal navigation, and mobile-responsive design. Input: validated pain points + company data. Output: complete report site with 5 page types.

Evidence & Validation

All claims in this report are evidence-backed:

  • Source Capture: Every evidence item includes its source URL with timestamp.
  • Multi-Model Triangulation: Pain points generated independently by 2-3 models; consensus findings retained.
  • Confidence Scoring: Each pain point scored 0-100% based on: evidence strength (40%), source diversity (20%), cross-model agreement (20%), industry context (20%).
  • Deduplication: Similar pain points merged using Jaccard word similarity (>=50% overlap).
  • Evidence Traceability: Every insight in Summary and Deep Market Analysis cites specific report data.

Chart Types

  • Confidence Chart: Bar chart of evidence confidence per pain point — High (>70%), Medium (40-69%), Low (<40%).
  • Phase Doughnut: Clusters pain points by event lifecycle phase (Pre-Event, During, Post-Event, Cross-Cutting).
  • Sell Radar: 5-axis radar chart for each company showing Solution Fit, Budget, Urgency, Strategy, Digital.
  • Evidence Bar: Horizontal bar chart of evidence sources: company statements, media, research, market data.

Limitations

  • Data Freshness: Analysis reflects data at crawl time. Rapidly changing companies may need updates.
  • LLM Hallucination: AI models may generate confident but incorrect claims. Validation layer reduces but cannot eliminate this risk.
  • Website Coverage: Some websites may block crawling. LLM knowledge used as fallback.
  • External Signals: LinkedIn hiring, news sentiment supplement but do not replace direct evidence.
